# Security Policy

## Reporting a vulnerability

Please do not publish sensitive vulnerability details in a public issue.

Open a private security advisory from the repository's **Security** tab when that feature is available. Include:

- the affected installer version or commit;
- the Linux distribution and architecture;
- exact reproduction steps;
- the expected and actual behavior;
- any relevant logs with secrets, tokens, IP addresses, and shared keys removed.

For vulnerabilities in Paqet itself rather than this installer, report them to the upstream [`hanselime/paqet`](https://github.com/hanselime/paqet) project.

## Supported versions

Security fixes are applied to the latest version on the `main` branch.
