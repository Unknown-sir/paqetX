# Changelog

All notable changes to this installer are documented here.

## [1.0.0] - 2026-08-02

### Added

- One-command Paqet server installation for systemd-based Linux systems.
- AMD64, ARM64, and ARMv7 release selection.
- Automatic dependency and network detection.
- SHA-256 verification using GitHub release asset digests.
- Secure configuration generation and idempotent firewall management.
- Hardened systemd units.
- Safe rerun behavior that preserves an existing configuration and version.
- Bilingual Persian and English documentation.
- GitHub Actions syntax and ShellCheck validation.
